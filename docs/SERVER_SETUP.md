# हिंदवी स्वराज्य ॲप - PC Signaling Server & Network Setup Guide

हा दस्तऐवज PC Signaling Server सुरू करणे आणि मोबाइल नेटवर्कवरून (इंटरनेट) PC शी सुरक्षित कनेक्शन कसे मिळवायचे याचे सविस्तर मार्गदर्शन करतो.

---

## १. PC Signaling Server काय आहे?

- PC Signaling Server हा केवळ **Signaling & Relay Server** आहे.
- **महत्त्वाचे:**
  - या सर्व्हरवर **कोणताही आर्थिक डेटा (Financial DB) साठवला जात नाही**.
  - मुख्य SQLite डेटाबेस **चालू खजानी (Latest Khajani) च्या फोनवरच सुरक्षित राहतो**.
  - सर्व्हर फक्त डिव्हाइस विनंत्या (Device Requests), डेव्हलपर मंजुरी (Approvals), परवानग्यांचे अपडेट्स (Permissions), डिव्हाइस रद्द (Revoke) आणि WebRTC फोन-टू-फोन कनेक्शन सुलभ करण्यासाठी वापरला जातो.

---

## २. सर्व्हर सुरू आणि बंद कसा करायचा? (Interactive CMD Control)

प्रोजेक्ट रूटमधील **`Start Server.cmd`** (किंवा **`Server Control.cmd`**) वर **Double-click** करा.

खालीलप्रमाणे परस्परसंवादी (Interactive) नियंत्रण मेनू उघडेल:
```text
============================================================
     HINDVI SWARAJYA APP - PC SIGNALING SERVER CONTROL
============================================================

  CURRENT STATUS: [ Server is OFF 🔴 ] (किंवा Server is ON 🟢)

============================================================
  MENU OPTIONS:
============================================================
  [1] Press 1 to Start Server
  [2] Press 2 to Stop Server
  [3] Press 3 to Check Server Status
  [4] Press 4 to Exit
============================================================

Enter your choice (1, 2, 3, or 4):
```

### पर्यायांची माहिती (Options Guide):
- **Press 1 (Start Server):**
  - सिस्टमवर Dart किंवा Python तपासेल.
  - Port 8080 वर Signaling Server सुरू करेल आणि स्वतंत्र विंडो उघडेल.
  - स्थिती लगेच **`Server is ON 🟢`** होईल.
- **Press 2 (Stop Server):**
  - Port 8080 वरील सर्व्हर प्रोसेस सुरक्षितपणे थांबवेल.
  - स्थिती लगेच **`Server is OFF 🔴`** होईल.
  - स्वतंत्रपणे **`Stop Server.cmd`** वर double-click करूनही सर्व्हर थेट बंद करता येतो.
- **Press 3 (Check Server Status):**
  - सर्व्हर चालू आहे की बंद हे तपासेल आणि मोबाईल ॲपसाठी Local IP पत्ते दाखवेल.
- **Press 4 (Exit):**
  - मेनूमधून सुरक्षितपणे बाहेर पडेल.

## २.१ ॲपमध्ये सर्व्हर स्थिती (App Server Status Indicator)
ॲपमध्ये खालील ठिकाणी सर्व्हर जोडणीची थेट स्थिती दिसते:
1. **Login स्क्रीन:** वरच्या उजव्या बाजूला थेट **`Server is ON 🟢`** किंवा **`Server is OFF 🔴`** दिसते.
2. **Dashboard (डॅशबोर्ड):** ॲप बारमध्ये थेट स्टेटस चिप दिसते, ज्यावर टॅप करून सर्व्हर तपशील व URL पाहता येते.
3. **Settings (सेटिंग्ज) -> Section 3 (रिमोट संप्रेषण):** सर्व्हर कार्डवर थेट **`Server is ON 🟢`** किंवा **`Server is OFF 🔴`** बॅज दिसतो.
4. **खजानी व्यवस्थापन (Khajani Management) स्क्रीन:** ॲप बारमध्ये थेट **`Server is ON 🟢`** किंवा **`Server is OFF 🔴`** बॅज दिसतो. टॅप करून URL कॉन्फिगर करता येते.


## ३. नेटवर्क कॉन्फिगरेशन पर्याय (Network Connectivity Options)

मोबाईल फोन आणि PC एकाच वाय-फाय नेटवर्कवर असल्यास किंवा मोबाईल बाहेर (4G/5G इंटरनेटवर) असल्यास खालील पर्याय वापरा:

### पर्याय अ: एकाच वाय-फाय (Same Wi-Fi / Local Area Network)
जर तुमचा फोन आणि PC एकाच वाय-फाय किंवा हॉटस्पॉटशी जोडलेले असतील:
1. `Start Server.cmd` मध्ये दिसणारा **Local IP** पहा (उदा. `192.168.1.100`).
2. ॲपमध्ये (Login स्क्रीनवर किंवा Settings मध्ये) **सर्व्हर पत्ता** टाका:
   `ws://192.168.1.100:8080`
3. 'जतन करा' (Save) वर क्लिक करा. कनेक्शन लगेच प्रस्थापित होईल.

---

### पर्याय ब: मोबाईल बाहेर असताना (4G/5G) - सुरक्षित Tunnel (शिफारस केलेला)
घरच्या PC ला पब्लिक आयपी नसतो किंवा राउटरवर पोर्ट फॉरवर्डिंग अवघड वाटल्यास **Cloudflare Tunnel** किंवा **Ngrok** वापरणे अत्यंत सोपे आणि १००% सुरक्षित आहे:

#### १. Cloudflare Tunnel (मोफत & कायमस्वरूपी):
```bash
cloudflared tunnel --url http://localhost:8080
```
किंवा

#### २. Ngrok वापरून (मोफत):
1. [ngrok.com](https://ngrok.com) वरून ngrok डाउनलोड करा.
2. CMD मध्ये चालवा:
   ```bash
   ngrok http 8080
   ```
3. Ngrok तुम्हाला एक URL देईल, जसे:
   `https://xyz123.ngrok-free.app`
4. ॲपमध्ये `https://` ऐवजी `wss://` वापरा:
   `wss://xyz123.ngrok-free.app`
5. आता तुमचा फोन जगात कुठूनही (4G/5G) तुमच्या PC सर्व्हरशी सुरक्षितपणे जोडला जाईल!

---

### पर्याय क: राउटर पोर्ट फॉरवर्डिंग (Router Port Forwarding)
जर तुमच्या ब्रॉडबँड कनेक्शनला Public IP / Static IP असेल:
1. आपल्या वाय-फाय राउटरच्या ॲडमिन पॅनेलमध्ये जा (`192.168.1.1`).
2. **Port Forwarding** किंवा **Virtual Server** मध्ये:
   - External Port: `8080`
   - Internal Port: `8080`
   - Internal IP: आपल्या PC चा Local IP (उदा. `192.168.1.100`)
   - Protocol: `TCP`
3. ॲपमध्ये Public IP सह URL प्रविष्ट करा:
   `ws://<YOUR_PUBLIC_IP>:8080`

## ४. ऑफलाइन-फर्स्ट वैशिष्ट्ये (Offline Guarantee)

- **लॉगिन आणि डॅशबोर्ड:** पीसी किंवा इंटरनेट बंद असले तरी मंजूर वापरकर्ते कोणत्याही अडथळ्याशिवाय ऑफलाइन लॉगिन करू शकतात.
- **आर्थिक नोंदी:** वर्गणी, देणगी, खर्च, पीडीएफ इत्यादी कामे स्थानिक फोनवर विनाइंटरनेट १००% चालतात.
- **रिमोट कामे:** नवीन डिव्हाइस विनंती, मंजुरी आणि रिमोट सिंकसाठीच केवळ इंटरनेट आणि पीसी सर्व्हर आवश्यक आहे.
